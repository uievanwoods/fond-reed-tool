# fond-reed-tool

Distributed Systems · Haskell · Go

折腾中的小玩具

## 用法

```bash
cat data.txt | cargo run
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/fond-reed-tool.git
cd fond-reed-tool
cargo build --release
```
